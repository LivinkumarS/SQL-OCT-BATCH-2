Database:
---------
>> Database is an organised collection of data that canbe easily accessed, managed and updated.

DBMS (Database Management System)
-----
This is a software to store and manage data efficiently.
Examples: MySQL, Oracle, MongoDB

RDBMS (Relational DBMS)
------------------------
>> Data will be stored in form of table(Rows and Column)
>> To work with RDBMS you must know SQL(Structured Query Language)
Ex: MySQL, Oracle


Non Relational DBMS 
--------------------
>> Data will be stored in the form of object, documents....(not in the form of table)
Ex: MongoDB, MariaDB

SQL(Structured Query Language)
-------------------------------
Syntax Rules 
------------
>> It is case-insensitive (a=A).
>> Every Query should end with ';'

Datatypes 
----------
Numeric
---------
INT ---> whole numbers
BIGINT --> stores large integers
FLOAT --> DECIMAL NUMBERS 

STRING 
-------
CHAR --> fixed length character string. Ex: char(5) ---> 'hello','world'
VARCHAR --> variable length character string. Ex: varchar(5) --> 'hello','hi'
TEXT --> store large amount of text.
ENUM --->

DATE and TIME 
--------------
DATE --> 'yyyy-mm-dd' ex: '2025-05-28'
TIME --> 'HH:MM:SS'

Constraint 
------------
PRIMARY KEY ---> It identifies each row uniquely. unique and not null. (only one PRIMARY KEY per table)

Opearators:
----------
>> it is symbol or keyword that perform operation on values.

basic operators 
----------------
=
<>, !=
<
>
<=
>=

BETWEEN --> Between two values (inclusive).
Ex: age BETWEEN 30 and 40;

IN and Not IN --> Matches any value in a list.
Ex: age In (val1,val2......);

PATTERN MATCHING --> LIKE Opearator (string Column) (matches string with a pattern).
Ex: col LIKE "pattern";
 
_ --> matches exactly one char.
% --> matches 0-inf char.

"a%" ---> ashwin, adherse, anand, a
"%a" ---> aruna,
"a___" --> arun
"% a _ _"

Logical Opearators
--------------------
AND --> both should be true
OR ---> any one should be true
NOT ---> invert

Queries 
--------
To create a database --> CREATE DATABASE name;
To select database --> USE dbname;
To create a new Table --> CREATE TABLE tbname (
    col1 datatype constraint,
    col2 datatype constraint,
    col3 datatype constraint,
    .
    .
);

To insert row into a table ---> INSERT INTO tbname (col definition(optional)) VALUES (),(),().....;
To retrive data from table ---> SELECT (col details --> when you want to fetch everything (*)) FROM tbname;
To update data --> UPDATE tbname SET col=val,col=val;
To delete a data --> DELETE FROM tbname;

SQL_SAFE_UPDATES=1 --> you cannot perform update or delete without filteration. condition must depend on primary key. you can update or delete only one row in one go.
