Database:
---------
>> Database is an organised collection of data that canbe easily accessed, managed and updated.

DBMS (Database Management System)
-----
This is a software to store and manage data efficiently.
Examples: MySQL, Oracle, MongoDB

RDBMS (Relational DBMS)
------------------------
>> Data will be stored in form of table(Rows and Column)
>> To work with RDBMS you must know SQL(Structured Query Language)
Ex: MySQL, Oracle


Non Relational DBMS 
--------------------
>> Data will be stored in the form of object, documents....(not in the form of table)
Ex: MongoDB, MariaDB

Constraint 
------------
>> It is a rule applied to a cloumn to limit the type of data that can go into a table

PRIMARY KEY ---> It identifies each row uniquely. unique and not null. (only one PRIMARY KEY per table).

FOREIGN KEY ---> To establish link bet ween two tables.
FOREIGN KEY (col) REFERENCES PRIMARY KEY of another table;
>> It refers to primary key of another table.

AUTO_INCREMENT --> It automatically generates sequential numbers. 1,2,3,4.....(used with primary key column)
UNIQUE --> Ensures no duplicates
NOT NULL --> Ensures no NULL
DEFAULT ---> assigns default value to a column

    .

Joins 
-------
>> It is used to combine rows from two or more tables based on related columns(foreign key)

INNER JOIN
------------
>> It returns only rows that have matching values in both tables.
EX: select..... INNER JOIN tableName ON expression;
select a.name,a.email,
l.movie as latestmovie
from actor a inner join latestmovie l ON 
a.id=l.actorId;

LEFT JOIN 
------------
>> It returns all the rows from left table and matches records from right table.
Ex: select..... LEFT JOIN tableName ON expression;

RIGHT JOIN 
------------
>> It returns all the rows from right table and matches records from left table.
Ex: select..... RIGHT JOIN tableName ON expression;

CROSS JOIN 
-----------
Produces cartesian product ---> every row of lef tb and every row of right tb.
Ex: select..... cross join tbname;

no of rows in result = rows of left * rows of right
